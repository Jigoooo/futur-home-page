# FUTUR Editorial Chapter 디자인

## 목표

현재 FUTUR의 밝고 신뢰감 있는 인상과 네이비·블루 브랜드 컬러는 유지한다. 전역 파란 그라데이션, 점이 붙은 영문 섹션 라벨, 반복 카드 장식을 덜어내고 큰 타이포·여백·화면 단위 전환으로 구성한 편집형 랜딩으로 정리한다.

참조 사이트 BrainAll의 중앙 3D 이미지와 콘텐츠를 복제하지 않는다. 단색 캔버스, 초대형 분할 타이포, 스크롤 진행에 맞춰 한 장면이 다음 장면으로 바뀌는 레이아웃 모션만 FUTUR의 실제 문구와 서비스 구조에 맞게 재해석한다.

## 시각 체계

- 전역 캔버스는 단색 웜 화이트 `#f7f7f3`로 변경한다.
- 섹션 내부의 방사형·선형 장식 그라데이션은 이번 작업 범위에서 제거한다. 네이비 서비스 챕터처럼 정보 구분을 위한 단색 면은 유지한다.
- Hero는 현재 제목, 설명, CTA 두 개를 유지하고 최대 1040px 폭의 2–3줄 타이포 레이아웃을 사용한다.
- `Our Services`, `Stack`, `Project Records`, `Our Team`, `Process`, `Operations`, `Review`, `FAQ`처럼 파란 점과 함께 쓰인 장식용 영문 라벨을 제거한다.
- 문의 폼의 `Project Brief`는 장식 라벨을 제거하되, 해당 입력 묶음의 접근 가능한 이름과 한국어 설명은 유지한다.
- 일반 콘텐츠는 카드보다 구분선, 열, 여백을 우선 사용한다. 기존 정보와 CTA는 삭제하지 않는다.

## 레이아웃 모션

- Hero 진입은 제목 줄, 설명, CTA 순으로 한 번만 실행한다. 이동 거리는 12px 이내로 유지한다.
- Hero 다음 핵심 서비스 구간은 단색 네이비 챕터로 전환한다.
- 데스크톱에서 서비스 챕터의 큰 제목은 화면에 고정되고, 오른쪽 서비스 내용이 스크롤 진행에 맞춰 순차적으로 이동·강조된다.
- 사례 영역은 섹션 전체가 한 번 진입한 뒤 내부 탭 전환만 기존 상호작용 모션을 사용한다. 모든 카드를 반복해서 등장시키지 않는다.
- 컴포넌트 단위의 버튼, FAQ, 탭, select 모션은 현재 동작을 유지한다.
- GSAP 3.15와 ScrollTrigger를 사용하며 Motion과 Anime.js는 구현 의존성으로 추가하지 않는다.
- 빠른 역방향 스크롤과 breakpoint 변경 시 GSAP 컨텍스트와 ScrollTrigger를 정리한다.

## 접근성과 성능

- `prefers-reduced-motion: reduce`에서는 pin, scrub, 이동, scale을 만들지 않는다. 콘텐츠는 최종 상태로 표시하고 색상·opacity 변화만 150ms 이내로 허용한다.
- 모바일에서는 pin을 사용하지 않고 동일한 콘텐츠를 정상 문서 흐름으로 배치한다.
- 애니메이션 대상은 transform, opacity, clip-path로 제한하며 blur와 상시 반복 애니메이션을 사용하지 않는다.
- 헤딩 계층과 section의 접근 가능한 이름은 장식 라벨 제거 후에도 유지한다.

## 보존 범위

- Resend 전송 로직과 환경변수
- 문의 폼 입력값, 검증, 성공·실패 상태
- 개인정보 수집·이용 동의 카드와 개인정보 국외 이전 동의 카드
- 기존 사용자 변경인 CI, Playwright 설정과 관련 E2E 파일
- 현재 공개된 서비스, 사례, 팀, 프로세스, FAQ 콘텐츠

## 검증

- 전역 배경에 gradient가 없고 단색으로 계산되는지 확인한다.
- 장식용 영문 kicker와 파란 점이 DOM과 화면에서 제거됐는지 확인한다.
- 1440×900, 1024×768, 390×844에서 Hero가 2–3줄을 유지하고 가로 overflow가 없는지 확인한다.
- 데스크톱 서비스 챕터의 pin·scrub 전환과 모바일 정상 문서 흐름을 확인한다.
- reduced-motion에서 ScrollTrigger 기반 이동이 생성되지 않는지 확인한다.
- 문의 폼 두 동의 영역과 Resend 전송 회귀 테스트를 유지한다.
- lint, typecheck, build, 관련 Playwright 테스트와 3000번 포트의 콘솔 오류 0건을 확인한다.
- 코드 변경 후 `graphify update .`를 실행한다.
