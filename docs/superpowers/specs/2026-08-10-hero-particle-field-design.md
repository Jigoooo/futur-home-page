# FUTUR Hero 고밀도 파티클 필드 설계

## 목표

현재 Hero의 낮은 밀도 점 구름을, 정교한 3차원 곡면과 포인터 궤적에 반응하는 고밀도 파티클 필드로 교체한다. Moment 홈페이지에서 확인한 시각 원리와 상호작용 구조를 참고하되 소스 코드는 복제하지 않고 자체 수학 곡면과 셰이더로 구현한다.

Hero 문구, 버튼, Header 전환, Resend 문의 전송, 개인정보 수집·이용 및 국외 이전 동의 영역은 유지한다.

## 레퍼런스에서 확인한 원리

- raw WebGL2 기반의 자체 파티클 렌더러를 사용한다.
- 메인 곡면 입자와 표면에서 이탈하는 보조 입자를 분리한다.
- 여러 매개변수 곡면 사이를 일정 시간 유지한 뒤 짧게 보간한다.
- 저해상도 밀도 버퍼를 별도로 렌더링하고 겹침이 많은 영역의 밝기를 비선형적으로 강화한다.
- 최근 포인터 궤적을 여러 점으로 보관하고, 이전 프레임 변위를 ping-pong 텍스처에 누적해 표면이 유체처럼 밀리고 복원되도록 한다.
- 입자의 크기, 불투명도, 색을 깊이와 밀도에 따라 달리해 단순한 평면 점무늬가 아닌 입체 표면으로 읽히게 한다.

## 시각 방향

- Hero 배경은 현재보다 어두운 단색 네이비 `#06152b`를 사용한다.
- 입자 기본색은 저채도 블루·청록이며 가까운 고밀도 영역만 옅은 시안으로 밝아진다.
- 글자 뒤에도 입자가 지나가지만 제목 대비를 해치지 않도록 입자 최대 밝기와 텍스트 주변 밀도를 제한한다.
- 네온 글로우, bloom, 그라디언트 배경, 영상, 가짜 UI는 추가하지 않는다.
- 화면 중심에 하나의 큰 곡면 덩어리를 두고 화면 가장자리에는 잔여 입자를 드물게 배치한다.

## 곡면과 변형

자체 구현한 네 가지 매개변수 곡면을 사용한다.

1. 접힌 리본: 넓은 면이 교차하며 안쪽과 바깥쪽 깊이가 드러나는 형태
2. 비대칭 토러스 매듭: 밀도가 높은 중심과 긴 꼬리가 함께 보이는 형태
3. 안장형 파동면: 넓게 펼쳐졌다가 중앙으로 접히는 형태
4. 이중 루프: 두 개의 흐름이 교차하면서 하나의 덩어리로 연결되는 형태

각 입자는 동일한 저불일치 수열 좌표를 공유한다. 따라서 곡면 사이를 보간할 때 입자가 무작위로 흩어지지 않고 표면이 연속적으로 접히는 것처럼 보인다.

- 곡면 유지: 약 5.8초
- 곡면 전환: 약 520ms
- easing: smoothstep
- 지속 회전: 매우 느린 축 회전과 미세한 호흡만 적용
- 무한 float, 랜덤 점프, 급격한 카메라 이동은 사용하지 않는다.

## 렌더링 구조

### 메인 파티클 패스

- 데스크톱: 약 55,000개
- 태블릿: 약 32,000개
- 모바일: 약 16,000개
- Halton 계열 저불일치 수열로 곡면 샘플을 균일하게 분배한다.
- 깊이에 따라 point size, alpha, 색온도, 포인터 영향량을 분리한다.

### 밀도 패스

- 128×128 단일 채널 부동소수점 framebuffer에 현재 곡면 밀도를 누적한다.
- 최종 fragment shader에서 `log(1 + density * scale)` 형태로 밝기를 강화한다.
- 밀도 강화는 중앙 덩어리에만 질량감을 주며 전체 화면이 밝아지지 않도록 상한을 둔다.

### 포인터 변위 패스

- 최근 포인터 좌표와 속도를 최대 24개까지 저장한다.
- 두 개의 저해상도 float texture를 교대로 사용해 변위를 누적한다.
- 새 포인터 충격을 더하고 매 프레임 damping을 적용한다.
- 포인터가 빠르게 움직일수록 넓고 길게, 느리게 움직일수록 작고 부드럽게 표면이 열린다.
- 입력이 끝나면 표면이 튀지 않고 서서히 원위치로 복원된다.

### 보조 입자 패스

- 데스크톱에서 최대 3,000개의 보조 입자를 사용한다.
- 포인터 궤적 부근의 표면 법선 방향으로 짧게 이탈한 뒤 감쇠한다.
- 독립적인 장식용 먼지가 아니라 표면 반응을 설명하는 범위에서만 표시한다.
- 모바일과 저전력 환경에서는 보조 입자를 생략한다.

## 성능과 폴백

- 신규 런타임 의존성을 추가하지 않고 기존 raw WebGL2 엔진을 확장한다.
- devicePixelRatio는 데스크톱 1.5, 모바일 1.2로 제한한다.
- Hero가 viewport 밖에 있거나 탭이 숨겨지면 RAF를 중단한다.
- `prefers-reduced-motion` 또는 Save-Data에서는 WebGL 시뮬레이션을 시작하지 않고 정적인 CSS 배경을 표시한다.
- WebGL2 또는 float color buffer를 사용할 수 없으면 오류를 노출하지 않고 정적 배경을 유지한다.
- resize 시 입자 버퍼는 재생성하지 않고 viewport와 투영 행렬만 갱신한다.

## 컴포넌트 경계

- `hero-particle-background.tsx`: 접근성, 환경 조건, visibility, pointer 입력, lifecycle만 담당한다.
- `hero-particle-engine.ts`: WebGL 리소스, 곡면 계산, framebuffer, 셰이더, 렌더 루프를 담당한다.
- Hero 컴포넌트에는 새로운 외부 공개 API를 추가하지 않는다.
- 디버깅 가능한 DOM 상태로 renderer 준비 상태와 depth/density/interaction 모드를 제공한다.

## 테스트 기준

- Hero 배경이 `#06152b`이고 캔버스 opacity가 1인지 확인한다.
- 데스크톱 렌더러가 고밀도·곡면·밀도·포인터 변위 모드로 준비되는지 확인한다.
- 일정 시간 후 곡면 프레임이 변화하고 곡면 식별자가 전환되는지 확인한다.
- 포인터 이동 시 궤적 샘플 수와 변위 활성 상태가 증가하고 입력 종료 후 감쇠하는지 확인한다.
- reduced-motion과 Save-Data에서는 WebGL 렌더러가 시작되지 않는지 확인한다.
- 1440×900, 1024×768, 390×844에서 제목 대비와 가로 overflow를 확인한다.
- Hero가 화면 밖으로 나가거나 탭이 숨겨졌을 때 렌더링이 중단되는지 확인한다.
- 기존 Hero SSR, Header, Contact/Resend 회귀 테스트를 유지한다.
- lint, typecheck, build, 관련 Playwright와 내부 브라우저 콘솔 오류 0건을 확인한다.

## 범위 제외

- Moment의 문구, 레이아웃, 로고, 브랜드 색상 또는 소스 코드 복제
- Three.js, React Three Fiber 또는 신규 모션 패키지 추가
- Hero 외 섹션의 디자인 변경
- Resend·문의 폼·동의 UI 변경
