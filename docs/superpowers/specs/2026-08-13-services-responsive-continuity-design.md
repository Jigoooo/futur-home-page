# Services 반응형 배경 연속성 설계

> **대체됨:** 이 문서의 밝은 인트로와 tablet/mobile 로컬 내비게이션 안은 더 이상 현재 설계가 아니다. 최종 계약은 `2026-08-13-hero-services-transition-typography-design.md`와 루트 `DESIGN.md`를 따른다. 이 문서는 이전 의사결정 기록으로만 보존한다.

## 문제

- 데스크톱에서 Services 인트로는 전체가 밝은 배경이지만 다음 레이아웃부터 왼쪽 40%만 검은색으로 바뀌어 전환 지점이 잘려 보인다.
- 1180px 이하에서는 1~4 서비스 인덱스가 큰 검은색 독립 블록으로 바뀌어 인트로와 각 챕터의 흐름을 끊는다.
- 모바일에서는 큰 인덱스 블록과 바로 이어지는 첫 챕터가 같은 정보를 반복하고, 스크롤 위치에 따라 플로팅 헤더가 첫 항목을 가릴 수 있다.

## 승인된 방향 A

### 데스크톱: 1181px 이상

- 인트로부터 서비스 챕터 끝까지 동일한 `40:60` 배경 축을 유지한다.
- 인트로 왼쪽 40%는 서비스 인덱스와 같은 검은색, 오른쪽 60%는 기존 밝은색을 사용한다.
- 인트로 제목과 설명은 오른쪽 60% 안에 배치한다.
- 기존 왼쪽 스티키 인덱스, 활성 상태, 82svh 챕터와 서비스 콘텐츠는 변경하지 않는다.

### 태블릿: 561px 이상 1180px 이하

- 검은색 인덱스 패널을 제거하고 인트로와 같은 밝은 배경을 사용한다.
- 1~4 링크를 한 줄의 로컬 내비게이션으로 배치한다.
- 카드, 외곽선, 배경 강조와 가로 스크롤을 사용하지 않는다.
- 활성 링크는 색상과 작은 위치 이동만 사용한다.

### 모바일: 560px 이하

- 같은 로컬 내비게이션을 2열 2행으로 배치한다.
- 충분한 터치 영역을 제공하고 긴 제목은 자연스럽게 줄바꿈한다.
- 플로팅 헤더 아래에 첫 항목이 가려지지 않도록 인덱스 영역의 흐름과 앵커 오프셋을 유지한다.
- 페이지 수준 가로 스크롤은 허용하지 않는다.

## 접근성·모션

- 네 개 링크는 실제 앵커와 `aria-current="step"`을 계속 사용한다.
- 키보드 포커스 표시를 유지한다.
- `prefers-reduced-motion`에서는 활성 링크 이동과 콘텐츠 전환을 제거한다.
- 새로운 장식, SVG, 이미지, 모션 라이브러리는 추가하지 않는다.

## 검증

- 1280px에서 인트로와 스티키 인덱스의 검은 배경 축이 같은 40% 폭으로 이어진다.
- 1180px와 900px에서 인덱스가 밝은 배경의 한 줄 내비게이션이며 가로 overflow가 없다.
- 390px에서 인덱스가 2열 2행이고 헤더와 겹치지 않으며 가로 overflow가 없다.
- 기존 서비스 앵커, 활성 상태, 데스크톱 스티키 동작과 reduced-motion 동작이 유지된다.

## 제외 범위

- 서비스 문구, 기술 섹션, FAQ, Footer, Hero는 변경하지 않는다.
- 서비스 데이터 구조와 활성 인덱스 훅은 변경하지 않는다.
