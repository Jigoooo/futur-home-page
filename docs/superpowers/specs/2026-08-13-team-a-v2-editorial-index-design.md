# Team A v2 Editorial Index Design

## Goal

현재 A안의 역할 인덱스 구조와 팀 문구는 유지하면서, 큰 제목과 넓은 공백, 균등한 4열 정렬에서 발생하는 발표 자료 같은 인상을 줄인다. 서비스 섹션과 다른 레이아웃 리듬은 그대로 유지한다.

## Approved direction

- `OUR TEAM` 영문 칩은 다시 추가하지 않는다.
- 제목과 설명은 왼쪽 정렬의 세로 묶음으로 유지한다.
- 제목과 역할 목록 사이 간격을 현재보다 약 절반으로 줄인다.
- 역할 행은 `코드 / 역할명 / 설명 / 태그`가 각각 독립된 표 칸처럼 보이지 않도록 재구성한다.
- 역할명과 설명을 하나의 본문 덩어리로 묶고 태그는 오른쪽 보조 정보로 둔다.
- 행의 최소 높이와 수직 여백을 줄여 연속해서 읽히는 웹 문서의 밀도를 만든다.
- 역할 행의 둥근 배경 hover는 제거한다.
- 데스크톱 hover에서는 역할명의 색과 위치만 작게 변한다.
- 등장 애니메이션은 위에서 아래로 읽는 순서에 맞춘 일회성 stagger를 유지한다.
- `prefers-reduced-motion: reduce`에서는 모든 항목을 즉시 표시한다.

## Desktop layout

각 역할은 작은 역할 코드와 하나의 본문 그룹, 오른쪽 태그 그룹으로 구성한다.

```text
PM      프로젝트 매니지먼트                  기획  문서화  커뮤니케이션
        요구사항과 범위를 정리하고 일정과
        의사결정을 연결합니다.
```

역할명과 설명은 같은 시작점에 놓여 하나의 설명 단위로 읽힌다. 태그는 설명보다 약한 대비로 오른쪽에 배치하되 별도의 카드나 칩으로 감싸지 않는다.

## Responsive behavior

- 중간 너비에서는 역할 코드와 본문을 첫 행에 두고 태그를 본문 아래로 내린다.
- 모바일에서는 `역할 코드 / 역할명 / 설명 / 태그` 순서의 단일 흐름으로 쌓는다.
- 모바일에서도 카드형 배경을 추가하지 않고 여백으로 항목을 구분한다.
- 390px에서 가로 넘침이 없어야 한다.

## Motion and interaction

- 역할 행은 `opacity`와 `translateY`만 사용해 60ms 간격으로 등장한다.
- hover는 배경이나 테두리를 만들지 않는다.
- 역할명은 최대 4px 이동하고 브랜드 파란색으로 전환한다.
- 정적 정보이므로 링크, 버튼, `tabIndex`를 추가하지 않는다.

## Verification

- 기본 URL과 `?team=a`에서 A v2가 렌더링된다.
- `OUR TEAM` 문구가 존재하지 않는다.
- 역할 5개와 역할 범위 15개가 모두 노출된다.
- 역할 행 내부에 링크, 버튼, 임의의 focus 대상이 없다.
- 등장 순서와 reduced-motion 동작을 검증한다.
- 1280px, 1024px, 390px에서 가로 넘침과 텍스트 충돌이 없다.
- 관련 Playwright, 접근성 검사, lint, build를 통과한다.
